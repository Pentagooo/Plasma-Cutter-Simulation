## 1. Worum es geht

Ein Bahnplaner für einen roboter­geführten Plasmaschneider. Aus einer
gegebenen Bauteil­geometrie (Kontur + Löcher) soll automatisch ein
**vollständiger, zeitoptimaler und kollisionsfreier Schneidplan** in
unter einer Sekunde berechnet werden.

**Schneidmodell („Lichtschwert"):** Der TCP fährt auf einem Offset-Pfad
mit konstantem Mindestabstand `MINIMUM_GAP = 3 mm` zum Material. Die
Plasmaklinge ragt Richtung Objekt mit geschwindigkeits­abhängiger Länge
`L(v) = blade_length − blade_slope · v` (linear, Parameter einstellbar).
**Coverage = Querschnittsfläche** (alle abgedeckten Gitterpunkte via
Swept Areas), nicht nur die Kontur.

**Bewertung:** `score = coverage · max(0, 1000 − Zeit)` — vor allem zählt
die Zeit, weniger ist besser.

**Anforderungen (roter Faden der BA):**
A1 Vollständigkeit · A2 Optimalität · A3 Echtzeit (< 1 s) · A4 Robustheit.

## 3. Wichtige Modell-/Design-Entscheidungen

- **Kein Überflug (Z-Hub):** bewusst entfernt (2026-06-12). Der Brenner
  kann nicht über das Material springen. Gibt es keinen kollisionsfreien
  2D-Übergang, liefert `LinkPlanner.plan()` `None`; der Sequencer
  verwirft die Kombination (`LinkInfeasibleError`). Folge:
  `test_lochjson` (umschlossene Lochkontur) wird korrekt als **nicht
  planbar** gemeldet.
- **Merge-Sicherheitsnetz im Auto-Planer:** Deckt ein verschmolzener Run
  weniger ab als seine Einzelsegmente (mehrteiliges Material → anderer
  Offset-Ring), zerfällt die Gruppe zurück in Einzel-Runs (Coverage-
  Garantie).
- **TCP-Densify-Fix:** TCP-Pfad wird vor der Swept-Area-Berechnung auf
  `TCP_SAMPLE_STEP = 3 mm` verdichtet (`_densify`), sonst fehlt der
  Klingen-Fächer an Ecken und Coverage wird unterschätzt.

## 5. Bedienung

```bash
# Simulation starten (Dialog)
python -m plasma_cutter.segment_simulation.simulation

# mit Parametern
python -m plasma_cutter.segment_simulation.simulation \
    --v-cut 5 --v-max 10 --blade-length 27.5 --blade-slope 1.5 --clearance 3
```

**UI:** Klick = Start/Ende · `A` = alles · `P` = Auto-Planer ·
`Enter` = planen + animieren · `U`/Rechtsklick = Undo · `R`/Button = Reset.
